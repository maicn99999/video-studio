Privacy Policy – Video Studio

Last updated: 2026-10-08

What the app does

Video Studio is a private desktop application used only by its owner to manage the owner's own YouTube channels. It uses the YouTube Data API to read the list of videos on the signed-in channel and to update the title, description, tags, thumbnail and privacy settings of the owner's own videos.

Data accessed

With the user's permission (Google OAuth, scope https://www.googleapis.com/auth/youtube), the app reads channel information and video metadata of the signed-in channel only.

How data is stored

The OAuth access token is stored only on the user's own computer. No data is sent to any server other than Google's APIs. The app has no backend server and does not collect, sell or share any personal data.

Google API Services User Data Policy

Video Studio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

You can revoke the app's access at any time at https://myaccount.google.com/permissions, and delete the local token file _youtube_token.json.
